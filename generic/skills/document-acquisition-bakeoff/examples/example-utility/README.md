# example-utility (synthetic bake-off evidence)

This folder is **evidence of bake-off ranking**, not a live collector. It shows how a short bake-off records `api` winning over `ui` for a fictional provider (`example-utility`), with a sanitized fixture and no real institutions, account numbers, cookies, or tokens. Operators point their own `code_root` at a private collector tree; nothing here connects to a real portal.
