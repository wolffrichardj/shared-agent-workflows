# Reinforce release notes

## 0.1.0 — 2026-11-10

First versioned standalone package of the public Reinforce skill.

- Route explicit lessons to approved memory, the owning workflow, deterministic helpers, or authoritative project guidance.
- Preserve host memory rules, existing authorization, and readback requirements.
- Add pinned manual installation, update/removal instructions, and a reproducible package with SHA-256 checksums.
- Retain the existing skill instructions unchanged from the public snapshot introduced in `f76c837`.

This is an initial 0.x release: the portable instructions are available for use, while native discovery and behavioral compatibility across hosts have not been established. Packaging, file integrity, and isolated copy installation were checked; these checks do not prove an agent will make the right persistence decision.

Only this package is MIT-licensed. No private harness files, unrelated skills, or Antigravity workflows are included.

## Version policy

Versions apply to Reinforce, not the entire repository. Release tags use `reinforce-vMAJOR.MINOR.PATCH`. During 0.x, changes to the workflow may occur in minor releases; corrections and documentation fixes use patch releases. A 1.0 release will mark a stable documented workflow after representative host behavior has been evaluated. Released archives are immutable; publish a new version for changes.
